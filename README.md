A small command line URL shortener written in Python, backed by MongoDB.

## What it does

- `--minify` takes a full URL and returns a short URL (e.g. `https://myur.ly/AzlUpL`).
- `--expand` takes a short URL and returns the original URL.

Short URLs expire after a configurable number of seconds:

- Minifying a URL that already has a valid short URL returns the same short URL.
- Once a short URL has expired, `--expand` no longer resolves it. Minifying the original URL again creates a new short URL.

Short codes are random strings of letters and digits, generated by the tool itself without an external library. Uniqueness is enforced by MongoDB unique indexes, and expired entries are removed automatically by a TTL index.

The tool only stores and resolves the mapping. It does not serve HTTP redirects. Input URLs must be `http` or `https` with a host; no further validation or normalization is done.

## Installation

### Database

```bash
cd database
cp .env.example .env        # then edit the values, see "Setup" below
docker compose up -d
```

On first start, `mongo-init.js` creates the database, the collection with its validator and indexes, and the application user. It only runs on an empty volume, so later changes to the database configuration need a manual migration or a fresh database. To recreate it from scratch:

```bash
docker compose down -v
docker compose up -d
```

## Setup

### `database/.env`

Used by Docker Compose to configure MongoDB.

- `MONGO_HOST`, `MONGO_PORT`: host interface and port where MongoDB is exposed.
- `MONGO_DATABASE_NAME`: database used by the application.
- `MONGO_COLLECTION_NAME`: collection that stores the URLs.
- `MONGO_ROOT_USERNAME`, `MONGO_ROOT_PASSWORD`: MongoDB admin account.
- `MONGO_APP_USERNAME`, `MONGO_APP_PASSWORD`: account used by the CLI (`readWrite` on the application database).
